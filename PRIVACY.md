# Privacy Policy

This application ("youtube-ai-generator") is a personal, non-commercial automation
pipeline that generates and uploads videos to a single YouTube channel owned by the
developer. It is not distributed to or used by any third party.

## Data accessed

The application uses the YouTube Data API v3 (`youtube.upload` scope) solely to
upload videos and set thumbnails on the developer's own YouTube channel, on the
developer's own behalf.

## Data storage and sharing

No data collected via the YouTube API is stored beyond what is strictly necessary
to perform the upload (the OAuth credentials required to authenticate the request).
No data is shared with, sold to, or processed by any third party.
